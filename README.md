# excel2latex

Excelの表をLaTeXのtabular形式に変換するツール（Web / CLI対応）  
Convert Excel tables to LaTeX tabular format (Web + CLI)

---

## Web版

https://potaajyu1729.github.io/excel2latex/

---

## CLI版

```bash
python excel2latex.py input.txt
```

---

## 使用上の注意

- タブ区切り入力のみ対応  
- 結合セルは非対応  
- 出力は基本的なLaTeX tabular形式
